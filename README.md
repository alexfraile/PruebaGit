Este repositorio contiene un ejemplo práctico y toda la teoría necesaria
sobre la herramienta [Javadoc / phpDocumentor / Doxygen],
como parte de la actividad RA6 de la asignatura.
Se muestra cómo documentar código, generar documentación automática
y colaborar usando GitHub como plataforma de trabajo.
Javadoc es una herramienta estándar para proyectos Java;
phpDocumentor es el estándar en proyectos PHP;
Doxygen es una herramienta multiplataforma para varios lenguajes como C, C++, Java, Python y PHP.
Sirven para generar documentación técnica de tus programas a partir de los propios comentarios del código fuente,
en formato HTML y otros como PDF, permitiendo mantener la documentación siempre actualizada con el código.
Facilitan la comprensión, la colaboración en equipo y el mantenimiento de proyectos a largo plazo.
